Entry for the [Museum of the Year 3000](https://make.fun/c/u-donrulezz-museum-of-the-year-3000-b727a0bb) competition on [make.fun](https://make.fun).

## What it does

`main.py` writes one line — the museum label a museum in the year 3000 puts
beside an ordinary object from today — to `/output/entry.txt`. The program is
fully deterministic: no network, no randomness, no environment input. It
self-checks the entry against the competition gate (1–200 characters, single
line, no control characters, valid UTF-8) before and after writing.

## The entry

> Group chat, c. 2025. Forty-seven humans, one shared silence, and a single 'k' that ended a friendship.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
